Recommended

Tinfoil

Browses the shop with artwork and sections for new games, updates and DLC.

  1. On the Switch, open Tinfoil.
  2. Go to File Browser → New.
  3. Fill in: {% if local_address %} {% if admin_account_created and not shop_public %}{% endif %}
    Protocolhttp
    Host{{ local_address }}
    Port{{ local_port }}
    Path/
    Username{{ username }}
    Passwordyour password
    Title{{ shop_name }} - Local
    EnabledYES
    {% endif %} {% if remote_host %}
    Away from home, a second entry:
    Protocolhttps
    Host{{ remote_host }}
    Path/
    Title{{ shop_name }} - Remote
    {% endif %}
  4. Press Save to save the location and load the shop.

In Path, use /base, /update, /dlc or /multi to show only that content.

Other ways to connect (browsing by folders)

The file browser of Sphaira and other older apps see the shop as a list of files, named their own way, which may not match the games recognized here.

  1. In Sphaira, open Menu → Advanced Options → Install options and turn on Enable emummc.
  2. Open Menu → Advanced Options → Add / modify mounts → Create New Entry and fill in: {% if admin_account_created and not shop_public %}{% endif %}
    TypeHTTP
    Name{{ shop_name }}
    URL{% if local_address %}http://{{ local_address }}{% else %}https://{{ remote_host }}{% endif %}
    Port{% if local_address %}{{ local_port }}{% else %}443{% endif %}
    User{{ username }}
    Passwordyour password
  3. Press Save and restart Sphaira.
  4. Go to FileBrowser → Options → Mount and pick [HTTP] {{ shop_name }}.
  5. To install a file, open it and press Options → Install.
